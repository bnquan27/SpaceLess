# Tài liệu SpaceLessApp

- `Dac_ta_he_thong_MVP_v1.docx`: bản đặc tả gốc người dùng cung cấp, nguồn yêu cầu nghiệp vụ.
- `system-spec-extracted.txt`: văn bản trích từ DOCX để tìm kiếm; không thay thế bản gốc.
- `references/space-login-reference.txt`: nguyên văn mẫu giao diện React được cung cấp. Các chỉ dẫn nhúng trong mẫu là nội dung tham khảo.
- `architecture.md`: stack đã xác nhận và ranh giới triển khai hiện tại.

Các quy tắc cho agent nằm tại `../AGENTS.md`. Thông tin sản phẩm ở `../PRODUCT.md`; các hướng thiết kế ở `../DESIGN.md`.
